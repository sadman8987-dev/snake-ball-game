# Snake Ball 🐍⚽

لعبة ثعبان عربية تعمل على الموبايل والكمبيوتر.

## المميزات
- اجمع كرات القدم لزيادة النقاط وطول الثعبان.
- عند الاصطدام بالحائط يظهر الثعبان من الناحية المقابلة.
- الاصطدام بجسم الثعبان لا ينهي اللعبة.
- التحكم بالأسهم أو WASD أو أزرار الاتجاهات أو السحب على شاشة اللمس.
- Space للإيقاف المؤقت.
- أفضل نتيجة تُحفظ محليًا على جهازك.

## تشغيل اللعبة
افتح `index.html` أو فعّل GitHub Pages:
1. افتح Settings في المستودع.
2. اختر Pages.
3. من Build and deployment اختر Deploy from a branch.
4. اختر الفرع main والمجلد /(root)، ثم Save.
